# results

Experiment outputs live here (created by the training scripts):

- `results/logs/` — CSV training logs (returns, per-seed runs)
- `results/videos/` — untrained / trained agent screen recordings

Both are produced by the commands in the top-level README and are small
enough to commit, so a fresh checkout has the baseline numbers and clips
without needing to re-run training.

> Plotting is not yet implemented here. `experiments/plot_results.py` is
> listed as a Week 4 deliverable and does not exist yet — the learning-curve
> and variance figures are still to be written.
