# results

Experiment outputs live here (created by training scripts, Week 3+):

- `results/logs/` — CSV training logs (returns, gradient norms, per-seed runs)
- `results/figures/` — plots generated by `experiments/plot_results.py`
- `results/videos/` — untrained / trained agent screen recordings

Generated files are committed here so the README reproduction commands
can rebuild every figure from raw logs.
